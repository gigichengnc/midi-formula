# Faculty note

MIDI Formula is an active undergraduate research/engineering prototype, not a finished publication release.

If you are reviewing this repository for research advice, the most useful starting points are:

1. [`README.md`](README.md) — concise project and research overview.
2. [`RESEARCH_PREVIEW.md`](RESEARCH_PREVIEW.md) — current pilot status and proposed study direction.
3. [PR #1](https://github.com/gigichengnc/midi-formula/pull/1) — original evidence/case-study layer.
4. [PR #2](https://github.com/gigichengnc/midi-formula/pull/2) — portable rough-first AI Composer SDK.
5. [`portable/midi_formula_sdk.py`](https://github.com/gigichengnc/midi-formula/blob/feature/ai-composer-sdk/portable/midi_formula_sdk.py) — the current one-file SDK used for coding-AI tests.

The current pilot has demonstrated feasibility but is too small for publication claims. The intended next step is methodology review before expanding the benchmark or collecting any human-participant data.
