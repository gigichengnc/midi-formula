# Reviewer orientation

This project is currently split across two stacked pull requests while the research-facing pilot release is being prepared.

- PR #1: evidence/case-study layer.
- PR #2: portable rough-first AI Composer SDK, stacked on PR #1.

Please treat current pilot results as feasibility observations rather than benchmark conclusions. The repository intentionally avoids claiming novelty for text-to-MIDI generation itself.

The intended research contribution, if the study is developed successfully, is cross-model evaluation of executable/editable symbolic-music programs, failure modes, and possible human-refinement value under a fixed transparent interface.
